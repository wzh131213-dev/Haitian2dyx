# 星际工坊 3D · Spaceflight Workshop

一个面向手机、iPad 和桌面浏览器的原创 3D 火箭建造与飞行游戏。参考了 Spaceflight Simulator 类游戏公开可见的玩法类型与页面介绍；不包含 GamePix 原作未公开源码、专有模型或广告。

https://wzh131213-dev.github.io/Haitian2dyx/

## 当前功能

- **三段式页面流程**：进入欢迎开始页 → 火箭建造页 → 发射准备页 → 全屏 3D 发射/飞行页。发射准备页会显示部件数量、估算起飞质量与当前任务；可返回建造继续修改。实际点火后隐藏零件库与任务面板，让飞行画面占满主要区域。

- **实时 3D 场景**：Three.js WebGL 渲染、程序生成的地球表面纹理、月球、火星、星空、金属材质、发射塔、地面网格、光照与动态火箭喷焰。
- **29 种航天器部件**：整流罩、载荷保护罩、指令舱、乘员舱段、小/中/大型/超大型燃料箱、真空发动机、海平面主发动机、核热推进发动机、固体助推器、级间分离器、直径转接段、空气动力翼、着陆支架、降落伞、太阳能板、RCS 姿控组件、反作用飞轮、对接端口、电池组、通信天线、科研仪器舱、行星探测车、服务舱、货运舱、卫星载荷和隔热盾。
- **构型编辑**：点击零件添加，桌面浏览器可将零件拖到 3D 视口添加；选中部件后可上移、下移或拆除。实时显示总质量、推力、估算推重比、结构高度与部件数。
- **推荐预设**：一键载入推荐两级火箭，或清空后从零搭建。
- **飞行控制**：发射、点火/熄火、油门调节、姿态转向、RCS 精细转向、级间分离、固体助推器抛弃、暂停/继续、降落伞部署。
- **载荷部署**：在飞行中释放卫星、科研舱、探测车或货运载荷；分离后的物体会独立漂移，火箭质量随之更新。
- **燃料与级段**：按部件记录剩余推进剂，支持多级火箭；分离时抛弃当前级段及其剩余质量，并切换到上一级燃料。
- **飞行轨迹**：飞行时记录轨迹点，可切换轨迹观察视角；高空时地面网格淡出，摄像机跟随火箭。
- **多种任务**：近地高度挑战、月球转移挑战、火星转移挑战、返回与着陆。
- **遥测与任务日志**：高度、速度、燃料、质量、推力、推重比、结构高度和飞行事件。
- **本地存档**：保存和读取火箭设计，使用当前浏览器的 `localStorage`，不会自动同步到其他设备。
- **窄屏操作**：小屏幕改用可切换的零件库/任务控制台抽屉，保留火箭视口与底部飞行按钮；适配 iPhone、iPad 和桌面浏览器。

## 操作指南

1. 在欢迎页点击“进入任务中心”，进入建造页。窄屏点击“零件”打开部件库；桌面浏览器可点按或拖动部件至 3D 视口。
2. 从“控制台”查看火箭结构。结构列表按**从上到下**显示；建造时选中部件后，可上移、下移或拆除。
3. 推荐先载入“推荐两级火箭”，选择任务后点击“发射”进入发射准备页，确认状态后点击“点火发射”。
4. 飞行时使用左右方向键或屏幕按钮改变姿态；油门滑块调节推力；“点火”切换发动机状态。
5. 底部“分离级段”会抛弃最下方级段；没有级间分离器时，可抛弃固体助推器。
6. 设计时安装降落伞后，飞行期间点击“展开伞”；安全着陆取决于高度、速度和当前构型。
7. 安装卫星载荷、科研仪器舱、探测车或货运舱后，可在飞行中点击“部署载荷”。通过“轨迹图”切换轨迹视角。
8. 键盘快捷键：左右方向键或 A/D 调整姿态；上方向键或 W 增加油门；Enter 分离级段；空格发射/暂停。

## 技术与运行要求

- 网页使用原生 HTML/CSS/JavaScript，3D 场景依靠从 jsDelivr CDN 加载的 Three.js 0.160.0。
- 首次打开需要网络访问 CDN；如果 CDN 被网络策略屏蔽，3D 视图无法初始化。
- 没有后端、账号系统或广告；数据仅保存在本机浏览器。
- 已完成内联 JavaScript 语法解析、DOM ID 引用与重复 ID 检查；没有执行真实 iPad 浏览器端到端试玩。

## 已知限制（重要）

这是独立制作的 3D 游戏化模拟器，不是 GamePix 原作的源码提取，也不包含原作的广告、专有资产或所有原版关卡。火箭零件由程序几何构建，不是高精度航天器 CAD 模型。飞行使用简化的推力、逐部件燃料、重力和气动近似；月球/火星任务是挑战模式，不代表已实现 N 体引力、真实星际转移、完整空间站建造或精确再入。页面视觉与操作流程仍需在真实 iPad 浏览器中体验验证。


## 飞行阶段改进
- 参考《Spaceflight Simulator》的逐步倾转、油门与级段操作，以及《Kerbal Space Program》的飞行遥测/姿态仪表思路，加入自动重力转弯辅助、垂直速度、预测远地点和姿态仪表。
- 这是本项目的原创简化实现，不是原作代码；当前仍未实现完整真实轨道力学、真实导航球和行星际引力模拟。
