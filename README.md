# 星际工坊 3D · Spaceflight Workshop

一个面向手机、iPad 和桌面浏览器的原创 3D 火箭建造与飞行游戏。参考了 Spaceflight Simulator 类游戏公开可见的玩法类型与页面介绍；不包含 GamePix 原作未公开源码、专有模型或广告。

## 在线运行

GitHub Pages 地址：  
https://wzh131213-dev.github.io/Haitian2dyx/

如果网页暂时显示 404，请到仓库 Settings → Pages，选择 **Deploy from a branch**，分支选 `main`、目录选 `/(root)`，然后保存并等待构建。

## 当前功能

- **实时 3D 场景**：Three.js WebGL 渲染、金属材质火箭、程序生成地球纹理、月球、星空、地面网格与光照。
- **火箭部件库**：整流罩、指令舱、乘员舱段、小/中/大型燃料箱、真空发动机、海平面主发动机、固体助推器、级间分离器、空气动力翼、着陆支架、降落伞、太阳能板、RCS 姿控组件、对接端口、卫星载荷和隔热盾。
- **构型编辑**：点击零件添加，选中结构后上移、下移或拆除；显示结构高度、质量、总推力与估算推重比；可载入推荐两级火箭或清空重做。
- **飞行控制**：发射、点火/熄火、油门调节、姿态转向、RCS 开关、级间分离、固体助推器抛弃、暂停/继续和降落伞部署。
- **多种任务**：近地轨道、月球转移、火星转移、返回与着陆挑战。
- **观察视角**：拖动画面旋转，滚轮/按钮缩放，重置视角与高空观察视角。
- **遥测与任务日志**：高度、速度、燃料、质量、推力、推重比、结构高度、飞行事件记录。
- **本地存档**：保存和读取火箭设计，使用当前浏览器的 `localStorage`，不会自动同步到其他设备。
- **适配触屏**：响应式界面、iPad/iPhone 触控按钮与键盘快捷操作。

## 操作指南

1. 从左侧零件库添加火箭部件。右侧结构列表按**从上到下**显示。
2. 选中部件，通过“上移 / 下移”调整堆叠顺序，或“拆除”移除部件。
3. 推荐先点“推荐两级火箭”体验预设，再点击“发射”。
4. 飞行时使用左右方向键或屏幕按钮改变姿态；油门滑块调节推力；“点火”切换发动机状态。
5. 点击“分离级段”抛弃分离器下方的级段；若仍有固体助推器，也可以抛弃。
6. 安装降落伞后，可在飞行期间点击“展开伞”；是否安全着陆取决于高度、速度和当前构型。
7. 使用“保存 / 读取”在同一浏览器保存和恢复设计。

## 技术与运行要求

- 网页使用原生 HTML/CSS/JavaScript，3D 场景依靠从 jsDelivr CDN 加载的 Three.js 0.160.0。
- 因为使用外部 3D 引擎，首次打开需要网络访问 CDN；如果 CDN 被网络策略屏蔽，3D 视图无法初始化。
- 没有后端、账号系统或广告；数据仅保存在本机浏览器。

## 已知限制（重要）

这是独立制作的 3D 游戏化模拟器，不是 GamePix 原作的源码提取，也不包含原作的广告、专有资产或所有原版关卡。火箭零件由程序几何构建，不是高精度航天器 CAD 模型。当前飞行使用简化的推力、燃料、重力和气动近似；月球/火星任务是目标挑战界面，不代表已实现 N 体引力、真实星际转移、完整轨道绘制、精确再入或空间站建造。页面布局与可用性仍需在真实 iPad 浏览器中体验验证。
