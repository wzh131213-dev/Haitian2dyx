# 星际工坊 2.0 · Rocket Flight

一个原创的浏览器火箭建造与飞行模拟小游戏，玩法方向参考太空火箭建造游戏，不包含原作代码、素材或关卡。

## 在线运行
如果仓库启用了 GitHub Pages，可访问：
https://wzh131213-dev.github.io/Haitian2dyx/

## 功能
- 点击添加指令舱、燃料箱、发动机、助推器、太阳能板和着陆支架
- 建造时拖动火箭部件调整堆叠顺序
- 发射、点火、转向、燃料消耗、级段分离
- 高度、速度、飞行时间、质量和燃料遥测
- 轨道示意视图
- 本地保存/读取设计
- 键盘与移动端触控操作
- 单文件 HTML，无外部依赖，无 API key

## 部署
在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存后等待部署完成。

## 限制
这是原创简化物理原型，不是原作的逐像素复制；轨道和动力学并非真实轨道力学模拟。
