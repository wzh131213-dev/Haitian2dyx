# Spaceflight Workshop · 星际航行

一个面向手机、iPad 和桌面浏览器的原创火箭建造与飞行小游戏。参考太空火箭建造游戏的玩法类型重新实现，不包含 GamePix 原作的未公开源代码、专有素材或关卡。

## 在线运行
启用 GitHub Pages 后可访问：  
https://wzh131213-dev.github.io/Haitian2dyx/

## 当前实现
- 单文件 HTML/CSS/JavaScript，无框架、无外部依赖、无需 API 密钥
- 火箭部件库：指令舱、燃料箱、主发动机、固体助推器、级间分离器、太阳能板、着陆支架、整流罩
- 建造、选择、调整部件顺序、拆除、保存和读取火箭设计
- 发射、点火/熄火、转向、燃料消耗、级段分离、暂停/继续
- 飞行场景与轨道示意视图、任务目标选择、遥测仪表和任务日志
- 键盘操作和适配 iPhone/iPad 的触控按钮
- 本地存档保存在当前浏览器，不会同步到其他设备

## 操作
- 点按左侧零件添加到火箭
- 选择部件后使用“上移 / 下移”调整排列；在建造画布中也可触摸部件并拖动调整
- 点击“发射”开始任务，再点击可暂停/继续
- “点火”启停发动机；左右方向键控制角度，上方向键推进
- Enter 分离级段；B 返回建造；R 重置
- 使用“轨道图”切换到示意视图

## 部署到 GitHub Pages
1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 里选择 Deploy from a branch。
3. Branch 选 main，目录选 /(root)，点击 Save。
4. 等待 Pages 构建完成，再打开上面的在线地址。
